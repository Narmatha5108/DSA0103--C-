# GitHub upload checklist

1. Extract this ZIP file.
2. Replace `REPLACE WITH YOUR NAME` and register-number placeholders.
3. Open the extracted folder and review every task's `.cpp` and notes.
4. In each task folder, compile and run the program yourself.
5. Save actual screenshots in that task's `outputs/` folder.
6. Upload the files/folders to the repository named `DSA01-<RegisterNumber>-Assignment1`.
7. Make separate commits for each task over time as your faculty requires. Do not claim that a one-time bulk upload satisfies progressive commits.
8. Share the repository with your faculty or make it public according to your course instructions.
9. Paste the GitHub URL into the report and README.
