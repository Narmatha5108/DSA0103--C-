# DSA01 Assignment 2 — C++ Code

These are example implementations for Tasks 1–7. Compile, run, understand, and adapt them; complete your own predictions and evidence before submission.

## Contents
- Task01: call by value, reference, pointer, return-by-reference expression, default arguments
- Task02: highest mark reference/copy/const reference and index/pointer alternatives; dangling reference warning demonstration (not called)
- Task03: courier charges using overloads and defaults
- Task04: savings account with 10-transaction circular history
- Task05: static ticket counter and array of objects
- Task06: friend and inline time functions
- Task07: shifting history compared with circular buffer redesign

## Compile and run
Example:
```bash
g++ -std=c++17 -Wall -Wextra Task01/Task01.cpp -o task01
./task01
```
Repeat for each source file. On Windows PowerShell, run `.	ask01.exe`.
